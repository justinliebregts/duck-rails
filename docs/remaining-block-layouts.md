# Remaining scavenging blocks - top-down studies

November 4, 2026. Drawing proposals only. User requested elevation changes so some blocks feel hilly. Terrain direction is authorized; exact heights, footprints and slopes remain proposed. No Unity assets changed.

Excludes the existing Depot, Motel and Campground studies. Passenger Station is a separate scavenging block from StartingStation.

## Common contract

96 x 160 m blocks; encounter Z=45..115. Preserve current track samples, entry/exit and stop. Proposed 6 m flat perimeter with height and slope blended to zero before the strip; flat railway and quiet approach/departure buffers. Building pads remain level. Paths nominally 3 m wide, targeting slopes no steeper than 1:12. Contour bands are schematic, not surveyed contours. Each detailed sheet includes a full-block plan and an exaggerated terrain section.

Six coal per variation, three per side; placements deferred to interior review. Retain gold counts, stable IDs and current east-side enemy coverage. Hills and interiors require offline crawlgraph and lighting rebakes; no runtime baking. Physical slope, drainage, loose-item recovery, low-eye sightlines and headset traversal remain unverified.
