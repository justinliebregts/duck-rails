# Batch: results table, revive SFX, train speed toggle, collapsed bridge (2026-11-21)

Harness: `Assets/Editor/Checks/Networking/RailQueueBatchLiveChecks.cs` (editor-only, no runtime instrumentation).
Two clients (main editor = master, MPPM Player2 = non-master) in one private room, three runs
(A: failure by all down; B: bridge crash; C: success preview). Logs: `batch-main.txt`, `batch-player2.txt`
(the harness's own `CASE` lines are in the main log; the repeating "TRAIN baseline" lines were trimmed).
Editor hooks: admin forced on both clients by reflection on `PlayerSession.IsAdmin` (main's real account is admin;
Player2's is not); master handoff focus forced (otherwise master moves to Player2 when main loses focus);
revive voices counted by polling AudioManager's private voice pool for SoundEvent `ReviveSFX`; the Test page of the
PauseMenu is activated so its Update refreshes the `TrainSpeed` label; non-master presses go through
`PauseMenuButton.Press()` then `Release()` (finger leaves; a momentary button only re-arms on exit).
